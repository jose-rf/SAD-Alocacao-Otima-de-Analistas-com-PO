## Tópicos a mencionar no TCC (anotação da planilha original)
- Teoria da decisão
- Soluções inexistentes, ilimitadas e múltiplas
- Origem da programação linear (surgiu após a Segunda Guerra Mundial)
- Origem do método Simplex (George Dantzig)
- Programação de metas (problemas com mais de um objetivo)
- Programação inteira / Programação mista
- Programação dinâmica
- Análise de sensibilidade
- POLP — Princípio do menor privilégio (justificativa para o sistema ser modular/limitado em vez de um único prompt livre)
